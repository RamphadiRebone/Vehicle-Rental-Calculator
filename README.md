# Vehicle-Rental-Calculator
A C# Windows Forms App to calculate car rentals,extras and VAT
### Features
* Calculates vehicle rental costs based on duration and car type.
* Input validation for alphabetic names and 10-digit phone numbers.
* Calculates subtotals, extras, and 15% VAT.
* Generates a digital receipt.
